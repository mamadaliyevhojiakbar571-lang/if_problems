## ⚖️ Shart Operatorlari (if1 - if12)
*Ushbu bo'limda dasturning qaror qabul qilish mantiqi va shartli o'tishlar o'rganilgan.*

| ID | Masala nomi va sharti | Kalit so'zlar |
|:---|:---|:---|
| **if1** | Musbat sonni 1 taga oshirish | `if n > 0` |
| **if2** | Musbatni +1, manfiyni -2 qilish | `if-else` |
| **if3** | Musbat (+1), manfiy (-2) va nol (10) holatlari | `if-elif-else` |
| **if4** | Uchta son ichidan musbatlar sonini sanash | `counter` |
| **if5** | Musbat va manfiy sonlar miqdorini aniqlash | `logic` |
| **if6** | Ikki sonning kattasini topish | `comparison` |
| **if7** | Ikki sonning kichigini tartib raqamini aniqlash | `index` |
| **if8** | Ikki sonni avval kattasini, keyin kichigini chiqarish | `sorting` |
| **if9** | A va B qiymatlarini (A < B) sharti bilan almashtirish | `swapping` |
| **if10** | Tenglikka qarab yig'indi yoki 0 ni o'zlashtirish | `assignment` |
| **if11** | Tenglikka qarab kattasini yoki 0 ni o'zlashtirish | `nested if` |
| **if12** | Uchta son ichidan eng kichigini topish | `min value` |# if_problems
